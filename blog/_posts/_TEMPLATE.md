To write a new post, copy this file and name the copy with today's date
and a short name, like 2026-12-01-best-christmas-horror.md
(lowercase words joined by dashes). The date in the name is the post's date.

Write the post here in plain text. A blank line starts a new paragraph.

Some handy formatting:

- *italics* for movie titles, **bold** for emphasis
- [link text](https://example.com) for links
- ## A heading for a new section
- Lines starting with "- " become a bulleted list

Pictures: upload the image into the blog/images folder on GitHub, then write
![short description](../images/my-picture.jpg)
